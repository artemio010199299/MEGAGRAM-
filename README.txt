MEGAGRAM — сайт с APK\n\nЗагрузите в корень репозитория GitHub: index.html, MEGAGRAM.apk и папку assets.\nЗатем Settings → Pages → Deploy from a branch → main → /(root) → Save.\n\nAPK — установочный файл Android. Перед установкой Android может показать предупреждение для приложений, установленных не из Play Маркета. Распространяйте файл только если это ваша собственная сборка и вы уверены в её происхождении.\n
