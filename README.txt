MEGAGRAM — сайт версии 5.0

В архиве:
- index.html — главная страница с новостью и историей обновлений 5.0
- MEGAGRAM.apk — APK, присланный автором проекта
- assets/ — папка ресурсов (пока не требуется сайту)

Публикация через GitHub Pages:
1. Распакуйте архив.
2. Загрузите СОДЕРЖИМОЕ папки MEGAGRAM_5_0_site в корень репозитория GitHub.
3. Убедитесь, что index.html и MEGAGRAM.apk находятся рядом в корне.
4. В Settings → Pages выберите Deploy from a branch, ветку main и папку /(root).

Важно: APK не проверялся на безопасность и работоспособность. Перед публикацией убедитесь, что готовы распространять его публично.
